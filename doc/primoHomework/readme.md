Homework 1 - Gestore Ospedale e Turni Ospedalieri

Repository: [Gruppo42fork](https://github.com/pasta-cyb/Gruppo42fork)

Il primo homework comprende il modello delle classi per la gestione di reparti, letti,
pazienti, ricoveri e turni dei medici. I dati sono mantenuti in memoria.

La classe contiene esempi di inserimento di ricoveri, assegnazione dei turni e registrazione
delle prestazioni, compresi alcuni casi con dati non validi.
